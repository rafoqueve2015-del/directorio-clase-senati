Progreso del Taller

Etapas del trabajo colaborativo con Git y GitHub.

01

Crear una rama

Branch

Creamos una rama independiente para desarrollar nuevas funcionalidades sin modificar directamente la rama principal.

git checkout -b nueva-rama
02

Guardar cambios

Commit

Registramos los cambios realizados en el proyecto con un mensaje que describe las modificaciones.

git add . git commit -m "Agregar cambios"
03

Subir cambios

Push

Enviamos nuestros commits al repositorio remoto para compartir el trabajo con los demás integrantes del equipo.

git push origin nueva-rama
04

Integrar cambios

Pull Request

Solicitamos revisar e integrar nuestros cambios en la rama principal mediante una Pull Request en GitHub.

GitHub → Pull requests
